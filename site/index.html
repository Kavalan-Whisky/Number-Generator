Module map

The src/core package, organized by responsibility. Each module is independently importable.

generators/

17 modules: random, prime, fibonacci, sequence, statistical, crypto, fractal, combinatorial, chaos, noise, quasirandom, digits, numbertheory, matrix, geometric, graph, cryptographic_sequences.

analyzers/

8 modules: statistical, randomness_tester (NIST-style), pattern_detector, distribution_fitter, entropy_analyzer, complexity_analyzer, time_series_analyzer, correlation tools.

transformers/

5 modules: number_formatter (Roman, words, Morse), sequence_transformer (EMA, delta-encode), encoder (base-N), numeral_systems (Gray, Zeckendorf, balanced ternary), signal_transformer (FIR, DFT, Hilbert).

pipeline/ · plugins/

Composable lazy Pipeline with Map, Filter, Take, and StatsSink stages. GeneratorRegistry plugin system with decorator registration.

cli/ · web/

Click CLI with Rich table output and progress bars. Flask REST API with a dark interactive dashboard. All generators accessible via HTTP endpoints.

database/

SQLAlchemy models for GenerationSession, GeneratedSequence, and AnalysisResult. A Repository class handles CRUD with query helpers.

utils/

math_utils (GCD, LCM, CRT, Euler totient, Möbius, continued fractions), cache (LRU, TTL, memoize), validators (range checking, type coercion).

tests/ — 807 tests

Full pytest suite. Each module has a dedicated test file. Run with pytest tests/ -q. 100 % passing on Python 3.11.

Usage

Install the dependencies and drive the toolkit from the CLI, the REST API, or directly in Python.

# Clone & install
git clone https://github.com/kavalan-whisky/number-generator.git
cd number-generator
pip install -r requirements.txt

# ── CLI ──────────────────────────────────────────────────
numgen generate random --algorithm lcg --seed 42 --count 100
numgen generate fibonacci --count 30 --variant matrix
numgen generate chaos --map logistic --r 3.99 --count 100
numgen generate digits --constant pi --count 50
numgen analyze randomness --input numbers.txt

# ── Python API ───────────────────────────────────────────
from src.core.generators.random_generator import LinearCongruentialGenerator
gen = LinearCongruentialGenerator(seed=42)
print(gen.generate(20, lo=0, hi=1000))

from src.core.generators.chaos_generator import LogisticMap
lm = LogisticMap(r=3.99, x0=0.42)
orbit = lm.generate(100)

from src.core.analyzers.entropy_analyzer import EntropyAnalyzer
report = EntropyAnalyzer().analyze(orbit)
print(report["shannon_entropy"])  # ≈ 3.3 bits

# ── REST API ─────────────────────────────────────────────
flask --app src.web.app run
# GET  /api/v1/generate/random?algorithm=lcg&seed=42&count=50
# GET  /api/v1/generate/fibonacci?count=30
# POST /api/v1/analyze/entropy  {sequence: [...]}

# ── Pipeline ─────────────────────────────────────────────
from src.core.pipeline.pipeline import Pipeline
from src.core.generators.prime_generator import sieve_of_eratosthenes

result = (Pipeline(sieve_of_eratosthenes(10000))
          .filter(lambda p: p % 4 == 1)  # Pythagorean primes
          .take(20)
          .collect())
