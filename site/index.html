Usage

Install the dependencies and drive it from the CLI, the API, or directly in Python.

# Install
pip install -r requirements.txt

# Generate from the CLI
numgen generate random --algorithm lcg --count 100 --min 0 --max 1000
numgen generate fibonacci --count 30 --variant matrix
numgen generate chaos --map logistic --r 3.99 --count 100
numgen generate digits --constant pi --count 100

# Or use it as a library
from src.core.generators.random_generator import LinearCongruentialGenerator
gen = LinearCongruentialGenerator(seed=42)
print(gen.generate(10, lo=0, hi=100))
